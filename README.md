## The word

**yikes**

One word an agent says when it has no idea what to do. An agent that is
completely lost does not say "error" or "unknown" — it says "yikes": a
startled little yelp, funny on its own, instantly readable, and exactly
what a machine caught out mid-task would blurt.

## How it works

`main.ts` prints the word to stdout and writes the exact same bytes to
`/output/entry.txt` (the grader's gate reads that file). The output is
deterministic: the bare word `yikes`, 5 characters, one word, no newline.

```sh
node main.ts
# yikes
```
